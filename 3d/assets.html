🧰 three.js フリーアセット図鑑

three.js で使える無料アセットを、種類ごとにその場で読み込んで見くらべられるページです。 デモに出てくるファイルはすべて three.js のリポジトリに入っているデモ用アセットで、CDN からそのまま読み込んでいます。 各セクションの下に、同じ種類のアセットを配っているサイトをまとめました。

  • ① 3Dモデル
  • ② HDRI 環境マップ
  • ③ PBRテクスチャ
  • ④ キャラ＆モーション
  • ⑤ 3Dテキスト用フォント
  • ⑥ 効果音・BGM
  • ⑦ ライセンスと軽量化
ネット接続が必要です。 three.js 本体とアセットを CDN（jsDelivr、だめなら unpkg）から読み込みます。 デモは下にスクロールして画面に入ったものから順に読み込むので、開いた直後に通信が集中することはありません。

013Dモデル（glTF / GLB）

three.js で最優先の形式は .glb（glTF のバイナリ版）です。メッシュ・マテリアル・テクスチャ・アニメーションが 1ファイルに入り、GLTFLoader だけで読めます。ボタンで切り替えて、ドラッグで回してみてください。

02HDRI 環境マップ

360度の高ダイナミックレンジ画像を scene.environment に入れるだけで、金属やガラスの映り込みと 全体の光がまとめて決まります。ライトを何個も置くより、HDRI 1枚のほうが早くきれいになります。

HDRI を配っているサイト

  • 🗄️ sIBL Archive HDRIの老舗アーカイブ。落ち着いた屋外ロケーションが中心で、古典的な定番素材が多い。 CC-BY-NC 中心

053Dテキスト用フォント

TextGeometry は専用の typeface.json が必要です。three.js に同梱の5書体をそのまま使えます。 文字を打ち替えて試してみてください（英数字のみ。日本語は同梱書体に字形が入っていません）。

07ライセンスと軽量化

アセットは「落とせる＝自由に使える」ではありません。公開前に必ず条件を確認してください。

表示意味公開ページで使うとき
CC0著作権を放棄（パブリックドメイン相当）表記不要・改変自由・商用可。いちばん扱いやすい
CC-BY表示（クレジット）が条件作者名・作品名・ライセンス・リンクをページ内に明記する
CC-BY-NC表示＋非営利のみ広告や販売のあるサイトでは使えない。個人の作品置き場なら可
独自規約サイト独自の利用規約「再配布不可」が多い。素材そのものを配る形になっていないか確認する
見落としやすい落とし穴。 ①静的サイトに .glb を置くと「素材の再配布」に当たる規約があります（Mixamo など）。 ②CC-BY はページのどこかに表記が必要で、ソースコードのコメントだけでは足りないと解釈されることがあります。 ③AI生成モデル配布サイトは、学習元の権利が不明なものが混ざります。仕事で使うなら CC0 のサイトに寄せるのが安全です。

読み込みのコード（このページで使っている書き方）

<script type="importmap">
{ "imports": {
    "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js",
    "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/"
} }
</script>

<script type="module">
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';

// モデル
const gltf = await new GLTFLoader().loadAsync('model.glb');
scene.add(gltf.scene);

// HDRI（環境光＋映り込み）
const hdr = await new RGBELoader().loadAsync('sky_1k.hdr');
hdr.mapping = THREE.EquirectangularReflectionMapping;
scene.environment = hdr;   // scene.background = hdr; で背景にも
</script>

Web に載せる前の軽量化

対象手段目安
形状Draco 圧縮（DRACOLoader）頂点データが 1/5 〜 1/10 に
形状Meshopt（gltfpack）Draco より展開が速い。アニメ付きに有利
テクスチャKTX2 / Basis（KTX2Loader）GPUメモリが 1/4 前後。JPEGより転送も軽い
テクスチャ解像度を落とすWebでは 1k〜2k で十分なことが多い
HDRI1k の .hdr を使う4k以上は背景を大写しにするとき以外は過剰

変換は glTF-Transform の CLI が便利です。 gltf-transform optimize in.glb out.glb --compress draco --texture-compress ktx2 のように1コマンドでまとめて処理できます。 ブラウザだけで済ませたいときは gltf.report で中身の内訳を確認できます。
