## こどもあそび

1歳ごろから遊べる知育あそびです。スコアも勝ち負けも制限時間もなく、画面のどこを触っても
必ず音や光で反応が返ります。ミニゲーム同様、通信も外部ライブラリも使っていません。

| あそび | 内容 |
| --- | --- |
| [しゃぼんだま](kids/bubbles.html) | 浮かぶシャボン玉をタッチするとポンッとはじけ、中の絵が飛び出す |
| [どうぶつタッチ](kids/animals.html) | どうぶつを押すと名前と鳴き声を大きく表示し、音声で読み上げる |
| [にじいろおえかき](kids/doodle.html) | なぞると虹色の線、ちょんと押すとスタンプ。線は1分ほどでふんわり消える |
| [おとあそび](kids/piano.html) | 6色のボタンがペンタトニック音階。どの順で押しても濁らない |
| [つみき](kids/blocks.html) | 触ると積み木が降ってきて積み上がる。少しのズレは自動で揃い、崩れても失敗にならない |
| [どうぶつつかまえ](kids/catch.html) | のはらを歩きまわるどうぶつをタッチで捕まえる。名前を読み上げ、6匹そろうとお祝い |

「つみき」は積み上げた高さに合わせてペンタトニック音階が上がっていき、数段ごとに紙吹雪でお祝いします。
画面の上まで届くと自動で片付くので、遊べなくなることがありません（右上の🧹ボタンの長押しでも片付きます）。

「どうぶつつかまえ」のどうぶつは逃げも隠れもせず、ゆっくり歩きながら少しずつ離れて重ならないようにします。
触れば必ずつかまり、かごが6匹でいっぱいになると紙吹雪でお祝いして、新しいどうぶつが出てきます。

小さな子どもの誤操作を防ぐため、各ページの🏠ボタンは**約1秒の長押し**で戻る仕組みです。
音はすべて Web Audio API で合成しており、音声ファイルは持ちません。

## 音が出ないときのための「音を出す」ボタン

ブラウザの自動再生ポリシーにより、`AudioContext` はページを開いた直後は `suspended` のままで、
ユーザー操作があるまで音が出ません。そこで音を鳴らす全ページ（こどもあそび6本と3Dあそび7本）に、
**押せば必ず音が出る入口**を1つずつ置いています。

| 表示 | 状態 |
| --- | --- |
| 🔇（点滅している） | まだ音を鳴らせない。押すと解除され、確認音が鳴る |
| 🔊 | 音が出る状態。押すと確認音が鳴る |

- こどもあそびと3Dのこども向けは🏠の右どなり、3Dフリースローは右上の視点ボタンのとなりに置いています
- ボタンを押さなくても、あそびの画面を触れば解除されます。そのときは `statechange` を拾って表示が自動で🔊に変わります
- タブを離れると中断されることがあるため、戻ってきたときにも表示を合わせ直します
- `prefers-reduced-motion` が有効な環境では点滅しません

なお、iPhoneの**消音スイッチがオン**のときや端末の音量がゼロのときは、このボタンを押しても音は出ません。

## 3Dあそび

Three.js（描画）と cannon-es（物理演算）をCDNから読み込んで動かす3Dページ集です。
ミニゲーム集やこどもあそびと違ってライブラリをネットワークから取得するため、表示にはネット接続が必要です。

| ライブラリ | 取得先 |
| --- | --- |
| [Three.js](https://threejs.org/) 0.160.0 | jsDelivr（失敗時は unpkg にフォールバック） |
| [cannon-es](https://pmndrs.github.io/cannon-es/) 0.20.0 | 同上。物理演算を使うページだけ読み込む |

### 共通モジュール

各ページで重なる部分は [3d/common.js](3d/common.js) にまとめてあり、ゲーム側は import して使います。
ビルドは不要で、ブラウザがそのまま ES モジュールとして読み込みます。

- CDNからのライブラリ読み込み（複数CDNを順に試す）と、読み込み中／失敗時の表示
- レンダラ・シーン・カメラ・描画ループ・標準ライト・画面座標からの拾い上げ
- Web Audio による合成音（ヨナ抜き音階なので、どの順に鳴っても濁らない）
- 🔇/🔊 のおとボタン、🏠 のながおしボタン、ヒント、おいわいの文字、紙吹雪

### こども向け（3さいごろから）

文字が読めなくても遊べます。しっぱいで終わることがなく、さわれば必ず音と動きが返ります。

| あそび | 内容 | そうさ |
| --- | --- | --- |
| [つみつみタワー](3d/stack.html) | 往復するブロックをつみあげ、はみ出した分は切れて落ちる | タップ |
| [ふうせんパチン](3d/balloons.html) | 浮かぶふうせんがはじけ、中から絵が飛び出す | タップ／なぞる |
| [さかなつり](3d/fishing.html) | つりばりを動かして、およぐさかなをつり上げる | ドラッグ |
| [ドミノたおし](3d/domino.html) | なぞるとドミノがならび、ボタンでつぎつぎ たおれる | なぞる＋ボタン |
| [くだものキャッチ](3d/fruits.html) | くまさんのかごでくだものをうけとめる | ドラッグ／←→ |
| [ボウリング](3d/bowling.html) | ボールをころがしてピンをたおす | スワイプ |

遊べなくならないように、次のような作りにしています。

- **つみつみタワー**：往復の幅をブロックの大きさに合わせ、一定より小さくならないようにしてある。
  のせそこねてもゲームオーバーにはせず、同じ大きさでやり直すだけ
- **ボウリング**：みぞにガードを置いてあるので、ねらいがそれてもかならずピンまでとどく。
  ピンは実物よりせまい間かくで、たおれやすくしてある
- **ふうせんパチン**：見た目より大きい当たり判定をつけて、小さな子でもさわりやすくしている
- **くだものキャッチ**：おとしてもしっぱいにならず、地面でぽとんとはじけるだけ

### ドミノたおしだけ物理エンジンを使っていない理由

cannon-es では「たおれたドミノが次のドミノを押し倒す」動きが安定して起きません。
うすい箱どうしの接触で力がうまく伝わらず、1枚目がとなりに もたれかかったところで止まってしまいます。
間かく・摩擦・厚み・刻み幅・接触の硬さ・反復回数を振って確かめましたが、どの組み合わせでも
2枚目が動きませんでした。そのため、たおれる動きだけは自前で順番に再生しています。
もたれかかって止まる角度は `asin((間かく − 厚み) ÷ 高さ)` と幾何から求めていて、
最後の1枚だけは よりかかる相手がいないので ぱたんと たおれます。

### 3Dフリースロー（おとな向け）

物理エンジンの挙動そのものを見るためのページです。スコアは数えません。

| 項目 | 内容 |
| --- | --- |
| 操作 | 上へドラッグでパワー、左右で狙い、離すとシュート。Space長押し→離す でも可 |
| カメラ | 右ドラッグで首振り、ホイールでズーム、1〜4 キーまたは右上のボタンで視点切替 |

コートの寸法はFIBA規格の実寸に合わせてあります（リング高3.05m・内径45.72cm、
バックボード1.80×1.05m、フリースローラインまで4.60m、7号球は半径11.9cm・620g）。

- リングは細いトーラスなので、当たり判定は小さな球28個を円周に並べた複合ボディで作っている
- すり抜け防止のため物理の刻み幅は 1/240 秒（1フレームあたり最大12回まで細かく進める）
- バックスピンはリングとの摩擦を通して効く（マグヌス力は cannon-es では計算されない）
- ネットは見た目のみで、ボールはすり抜ける
- 外した／止まった／転がっていった ボールは自動で手元に戻る

パワーゲージの白い目盛りは「その角度でリング中心を通る計算上の初速」で、
ボールに太さがあるぶん、角度が低いと目盛りどおりでもリングに当たります。
