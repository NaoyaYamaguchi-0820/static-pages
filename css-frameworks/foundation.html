よくある質問

  • 既存のドキュメントを移行できますか？

    Markdown / Word / Confluence からの一括インポートに対応しています。

  • オフラインでも使えますか？

    デスクトップアプリで下書きの編集が可能です。復帰時に自動同期します。

  • データはどこに保存されますか？

    東京リージョンに保存され、日次でバックアップされます。

Foundationらしさ： 挙動は data-accordion のような属性で宣言し、 最後に $(document).foundation() を1回呼ぶだけで有効化されます。

Foundation の特徴

👍 長所
  • XY Grid が強力。縦横どちらの分割にも同じ書き方で対応できる
  • Abide（フォーム検証）、Interchange（レスポンシブ画像・コンテンツ差し替え）など他にはない実務機能
  • アクセシビリティ対応が丁寧で、公的機関・大規模サイトでの採用実績が多い
  • 装飾が控えめなので、独自デザインを載せても浮きにくい
  • 姉妹版の Foundation for Emails でHTMLメールも作れる
⚠️ 短所・注意点
  • jQueryが必須。モダンな構成では負債になりやすい
  • 開発の勢いは Bootstrap / Tailwind に比べて落ち着いている
  • 日本語の情報が少なく、公式ドキュメント頼りになりがち
  • カスタマイズは Sass 前提の設計で、CDNのみだと調整余地が狭い
向いているケース

大規模コーポレートサイト、アクセシビリティ要件が明確な案件、HTMLメール制作。すでにjQueryが入っている既存システムの刷新とも相性が良好です。

CDNの書き方
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/foundation-sites@6.9.0/dist/css/foundation.min.css">
