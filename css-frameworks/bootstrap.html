Bootstrap の特徴

長所

  • ナビ・モーダル・トースト・オフキャンバスまで必要なコンポーネントがほぼ全部揃う
  • 日本語情報・書籍・求人が圧倒的に多く、チーム全員が最初から読める
  • v5でjQuery依存を撤廃。data-bs-* 属性だけで挙動が付く
  • v5.3のカラーモード（data-bs-theme）でダーク対応が数行
  • d-flex gap-3 などユーティリティも充実し、微調整でCSSを書かずに済む

短所・注意点

  • 既定のデザインが強く、「Bootstrapらしさ」が出やすい
  • デザインを大きく変えるならSass再ビルドが実質必須
  • 全部入りCSSは30KB(gzip)。使わないコンポーネントも読み込まれる
  • クラス名が長くなりHTMLが冗長になりがち

向いているケース

社内システム・管理画面・短納期の受託案件など、デザインの独自性より速度と安定性が求められる場面。人の入れ替わりがあるチームでも学習コストが低く保てます。
