    • オフラインでも使えますか？

    UIkit の特徴

    👍 長所

    • 属性を書くだけでモーダル・スライダー・スクロール演出・通知が動く
    • アニメーション・トランジションの完成度が高く、動きのあるLPが最速で作れる
    • SVGアイコンセット（uk-icon）が同梱され、追加読み込み不要
    • グリッドが柔軟（uk-child-width-1-3@m のようにブレークポイント指定が簡潔）
    • コンポーネント同士のデザインの統一感が非常に高い

    ⚠️ 短所・注意点

    • JSが必須で、gzip後でも約51KB。静的サイトには重く感じる場合がある
    • 独自のクラス体系（すべて uk- 接頭辞）で、他フレームワークの知識が流用しにくい
    • 日本語情報が少なく、公式ドキュメント（英語）が主な情報源
    • デザインの個性が強く、大幅に変えるならLESS/SCSSの再ビルドが必要
    • 商用利用は無料だが、Pro版（有料）との機能差がある

    向いているケース

    動きのあるコーポレートサイト・LP、短期間で見栄えのするプロトタイプを作る場面。「JSは書きたくないが動きは欲しい」という要求に最も強く応えます。
