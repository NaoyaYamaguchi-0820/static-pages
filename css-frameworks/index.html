🧪 CSS Framework Comparison

CSSフレームワーク比較デモ集

主要なCSSフレームワーク10種を、まったく同じ題材（架空のSaaS「Aurora Notes」のランディングページ）で実装しました。 すべてCDN読み込みのみ・ビルド不要で、1ファイルで完結しています。 同じ画面を並べて見ることで、クラス設計の思想・記述量・付属コンポーネントの差がそのまま比較できます。

各ページの最後には「このフレームワークの特徴・長所・短所・向いているケース」をまとめてあります。

🎨 Materialize

マテリアルデザインをそのまま実装。影・FAB・リップルの世界観が一発で出る。

デザイン特化JS同梱22KB gzip

📚 Fomantic UI

コンポーネント型jQuery必須181KB gzip

🥧 Pico.css

クラスレス。素のHTMLタグを書くだけで整う。管理画面や資料サイトに最適。

クラスレスJSなし11KB gzip

軽量型JSなし9KB gzip

選び方のめやす

「とにかく早く形にしたい・チームの人数が多い」→ Bootstrap。情報量と採用実績が圧倒的で、迷ったときの安全牌です。

「デザインカンプ通りに作りたい」→ Tailwind CSS。既定の見た目を打ち消す作業が発生しません。ただし本番はビルド前提。

「JSを一切増やしたくない」→ Bulma / Spectre.css。CSSだけで完結し、挙動が必要な部分だけ自分で書けます。

「HTMLを書くだけで整えたい」→ Pico.css。クラス名を覚える必要がなく、社内ツールなら十分な品質になります。

「動きのあるLPを最速で」→ UIkit。モーダル・スライダー・スクロール演出が属性だけで動きます。

「デザインシステムを自作する」→ Open Props。色・余白・影・イージングの土台だけを借り、見た目は完全に自分で決めます。

比較の条件

・すべてのページで同じ内容（ヒーロー／機能3件／料金3プラン／開閉パネル or モーダル／問い合わせフォーム）を実装しています。

・すべてCDN読み込みのみ、ビルドツール・パッケージ管理なし。ページを開けばそのまま動きます。

・各フレームワークの「らしさ」が出る機能を意図的に使っています（例：Bootstrapのカラーモード、Bulmaのスケルトン、UIkitのスクロール演出、Picoのクラスレス）。

・CDN配信のため、初回表示時はネットワーク接続が必要です。

Aurora Notes は比較用の架空サービスです。各フレームワークのロゴ・商標はそれぞれの権利者に帰属します。
