よくある質問

既存のドキュメントを移行できますか？

Markdown / Word / Confluence からの一括インポートに対応しています。

オフラインでも使えますか？

デスクトップアプリで下書きの編集が可能です。復帰時に自動同期します。

データはどこに保存されますか？

東京リージョンに保存され、日次でバックアップされます。

Fomantic UIらしさ

ui styled fluid accordion のように、クラスを英語の修飾語として重ねていきます。 初期化は $('.ui.accordion').accordion() のjQueryプラグイン形式です。

Fomantic UI の特徴

👍 長所
  • クラス名が英語の文章として読める（ui three column stackable grid）
  • コンポーネント数が最多クラス。statistic / step / ribbon / feed など他には無い部品も揃う
  • フォーム検証・カレンダー・検索候補など、アプリ寄りの機能が標準装備
  • テーマ機能が強力で、変数を差し替えるだけで全体の印象を変えられる
  • Semantic UI（開発停滞）のコミュニティ後継として現在も更新が続いている
⚠️ 短所・注意点
  • とにかく重い。全部入りCSSは gzip後で約181KB、JSも約105KB
  • jQueryが必須。React / Vue との組み合わせは相性が悪い
  • 必要なコンポーネントだけ読み込む構成にするにはビルド設定が要る
  • クラスの語順・組み合わせに独自ルールがあり、慣れるまで戸惑いやすい
  • 日本語情報は Semantic UI 時代のものが多く、最新版と食い違うことがある

向いているケース

社内向け管理画面やダッシュボードなど、コンポーネントの多さがそのまま開発速度になる場面。ページ表示速度より機能網羅性が優先される用途に向きます。
